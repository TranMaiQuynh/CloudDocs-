
# CloudDocs - Collaborative Document Management System

Dự án Hệ thống quản lý tài liệu nhóm học tập trên Cloud sử dụng FastAPI (Backend) và React (Frontend).

## Hướng dẫn cài đặt Backend

1. Di chuyển vào thư mục backend:
   ```bash
   cd backend
   ```

2. Kích hoạt môi trường ảo:
   ```bash
   .venv\Scripts\activate
   ```

3. Cài đặt thư viện:
   ```bash
   pip install -r requirements.txt
   ```

4. Chạy server:
   ```bash
   uvicorn app.main:app --reload
   ```
